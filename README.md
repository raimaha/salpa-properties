# Salpa Properties website

The website for **Salpa Properties Limited**, live at https://salpaproperties.co.uk (hosted on Netlify).

## How to edit the text

1. Click **index.html** above, then click the **pencil icon** (Edit this file).
2. Press **Ctrl+F** (Cmd+F on Mac) and search for the words you want to change.
3. Change only the words between the tags. Do not change anything inside `< >`.
4. Click the green **Commit changes** button.
5. Netlify updates the live site automatically within about 30 seconds.

Each section of the page is marked with an `EDIT HERE` note so it's easy to find.
